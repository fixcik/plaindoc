Корпуса для оценки таблиц PDF (собрано 2026-11-06/07)

1. PubTables-1M (подмножество), папка corpus/pubtables1m/
   - Аннотации: https://huggingface.co/datasets/bsmock/pubtables-1m (CDLA-Permissive-2.0),
     файл PubTables-1M-PDF_Annotations.tar.gz (3,7 ГБ) прочитан потоком: взяты первые 250 МБ сжатого потока
     (27 160 JSON-файлов, по одному на статью), после выбора подмножества лишние удалены; осталось 449 (ann/, 71 МБ).
   - Выбор (corpus-scripts/pt1m_select.py, seed 1): документы, у которых есть >=1 таблица без флагов
     exclude_for_detection/exclude_for_structure. Аннотации в координатах PDF (top-origin), с ячейками
     (row_nums/column_nums -> rowspan/colspan, текст pdf_text_content), bbox таблиц, строк, колонок.
   - PDF: официальный облачный бакет PMC Open Access (AWS Open Data, без логина):
     https://pmc-oa-opendata.s3.amazonaws.com/<PMCID>.1/<PMCID>.1.pdf ; 449 из 450 скачаны (1 не найден), 804 МБ.
     Лицензии статей: PMC OA Subset (CC-BY и др., по статье); условия NLM — ftp.ncbi.nlm.nih.gov/pub/pmc/readme.txt.
   - Итог: 449 документов, 4968 страниц, 1081 таблица (624 с объединёнными ячейками), 4061 страница без таблиц.
     Согласованность эталона с дампом pdf_oxide: 96,6 % токенов эталонных ячеек найдены среди слов внутри bbox
     (медиана 1,0; <0,5 у 17 таблиц из 1078) — PDF те же, что использовались при разметке.
   - Известная неполнота эталона: в сборниках тезисов (например PMC4471334, PMC4601848, PMC4700083) часть реальных
     таблиц не размечена (в XML статьи их нет) — такие срабатывания считаются «ложными»; доля таких случаев
     оценена через документы >30 страниц (22 FP из 298) и выборочный просмотр.

2. ICDAR 2013 Table Competition, папка corpus/icdar2013/
   - https://www.tamirhassan.com/html/files/icdar2013-competition-dataset-with-gt.zip (5,6 МБ), 67 PDF
     (27 EU + 40 US gov), 238 страниц, 150 таблиц = 158 регионов (регион = часть таблицы на странице), XML
     -str.xml с ячейками (start/end-row/col, bbox в PDF-координатах bottom-origin, content). Лицензия на странице
     не указана; датасет конкурса (Göbel et al., ICDAR 2013), используется для исследовательской оценки.
   - 110 страниц без таблиц.

3. opendataloader-bench (старый корпус), samples/odl-bench: 200 одностраничных PDF, 55 таблиц в 42 файлах,
   158 файлов без таблиц; эталон HTML в markdown.

Проверенные, но не взятые:
   - OmniDocBench (opendatalab, CC-BY-NC-4.0): в ветке main только изображения страниц + JSON; в ветке v1_0 папка
     ori_pdfs содержит лишь 12 PDF (6,4 МБ) — PDF-слой для всего набора недоступен.
   - FinTabNet (IBM DAX): страница DAX закрыта («deprecated»), PDF доступны только через Kaggle (нужен логин);
     на HF (bsmock/FinTabNet.c) только аннотации (255 МБ) и изображения.
   - SciTSR (Google Drive, MIT для репозитория): 15 000 PDF по одной таблице (обрезанные, без контекста страницы);
     не годится для оценки ложных срабатываний, не скачан.
   - PubTabNet, TableBank, DocBank, cTDaR 2019, DocLayNet: изображения (DocLayNet — PDF 7,5 ГБ, без структуры ячеек).

Разбиение для подбора порогов: train = чётные документы отсортированного списка pt1m (225) + icdar (34);
test = нечётные (224 + 33) + весь ODL (200). ODL — чистый holdout для фильтра (сам детектор настраивался на ODL).
